# Sprint S2 — Design System

> **Estado:** Concluída e aceita
> **Registro:** retrospectivo, reconstruído a partir da documentação aceita

## Objetivo

Criar uma linguagem visual compartilhada, baseada em Material 3 e nos tokens do
MykytaDu.

## Entregue

- temas claro e escuro;
- Poppins em Compose Resources;
- tokens de cores, tipografia, shapes, dimensões e ícones;
- `AppButton`, `AppTextField`, `AppCard`, `AppTopBar`, `AppSearchBar`;
- `AppChip`, `AppIconButton`, `AppDialog`, `AppDivider`;
- componentes de loading, progresso, erro e estado vazio;
- `DesignSystemShowcase` para inspeção técnica.

## Evoluções aceitas

Os contratos dos componentes foram ajustados para centralizar estado, cores,
acessibilidade e comportamento. A identidade vigente está em
[`identidade-visual.md`](../identidade-visual.md); a estrutura atual dos
componentes é determinada pelo código.

## Critérios aceitos

- temas e tokens centralizados;
- telas sem cores fixas próprias;
- componentes reutilizáveis;
- tema aplicado na composição compartilhada.

## Encerramento

O Design System foi aceito como base das telas posteriores. Refinamentos de UX
e acabamento que não bloqueiam funcionalidades permanecem para a Sprint 16.
