## Prioridade das fontes

Quando houver divergências, considere esta ordem:

1. código atual;
2. builds e testes efetivamente executados;
3. implementações e validações recentemente aceitas;
4. Documento Mestre;
5. Modelagem;
6. Roadmap;
7. documentos históricos.

Cada informação deve permanecer no documento responsável por ela. Planejamento
não comprova implementação, e propostas futuras devem ser identificadas
explicitamente.
