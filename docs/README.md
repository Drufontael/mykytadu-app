## Prioridade das fontes

Quando houver divergências, considere esta ordem:

1. código atual;
2. implementações e validações recentes;
3. Documento Mestre;
4. Modelagem;
5. Roadmap;
6. documentos históricos.

Os documentos devem acompanhar as decisões consolidadas no código e diferenciar claramente funcionalidades implementadas de propostas futuras.
